客户端下载与操作说明

ByWave 以机场订阅为核心，兼容常见开源与商业代理客户端。请先完成套餐开通，再按下列步骤配置，避免使用来路不明的安装包。

推荐操作步骤

  1. 在本官网选定基础版、旗舰版或团队版并完成开通。
  2. 登录账户后台复制订阅链接（Clash / 通用订阅格式）。
  3. 在电脑或手机安装兼容客户端，例如支持 Clash 内核或 Shadowsocks 协议的工具。
  4. 于客户端「订阅」或「配置」中粘贴 ByWave 链接并更新节点。
  5. 根据延迟与解锁标签选择节点，开启系统代理或增强模式后即可加速访问。

平台提示

Windows 与 macOS 可使用图形化代理面板；Android 可选用支持订阅的应用；iOS 需通过外部商店获取兼容软件。ByWave 不提供安装包托管，官方下载指引仅覆盖订阅导入与节点使用方法。遇到连接问题可优先切换协议或更换邻近节点。

常见问题

以下为用户在官网下载与使用过程中最常咨询的内容，点击问题即可展开说明。

ByWave 机场和 VPN 客户端有什么区别？

机场指提供订阅链接与节点列表的服务，用户可在 Clash 等客户端中灵活分流；传统 VPN 模式则由客户端一键连接单一通道。ByWave 同时支持两种用法，进阶用户更常使用机场订阅以获得规则与多节点切换。

如何在官网完成客户端配置？

无需在本站直接下载安装文件。完成套餐后复制订阅，打开已安装的兼容客户端，添加订阅 URL，更新后再选择节点连接。详细步骤见上方「操作说明」。

流量用尽或设备超限会怎样？

当月流量耗尽后新连接将受限，次月自动重置。同时在线设备超过套餐上限时，部分会话可能被踢出。建议升级至旗舰版或团队版，或错峰使用。

ByWave 能否稳定解锁流媒体？

基础版提供基础解锁，旗舰版与团队版强调全节点原生解锁。实际播放成功率受平台风控影响，可尝试切换已标注流媒体的线路。游戏方面，旗舰版 IPLC 对部分区服延迟更友好。

年付如何计算，能否退款？

年付价格已在各套餐卡片标明，相当于按月购买约十个月的价格。因属虚拟加速服务，开通后一般不支持无理由退款，请在购买前确认设备数与流量需求。企业定制可联系团队版客户经理。

节点在哪些地区，速度如何？

ByWave 维护多地区普通线路与部分专线。日常网页与视频以优化过的国际出口为主，晚高峰可能波动。旗舰与团队用户可优先使用高带宽与 IPLC 节点。具体延迟请以客户端测速为准。
